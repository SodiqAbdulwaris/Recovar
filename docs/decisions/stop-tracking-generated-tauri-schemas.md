# Decision: stop tracking Tauri's generated capability schemas

## What changed

Added `dist/` and `recovar-gui/src-tauri/gen/schemas/` to `.gitignore` and removed the
existing `gen/schemas/*.json` files from git tracking.

## Why

`recovar-gui/src-tauri/gen/schemas/*.json` (`acl-manifests.json`, `capabilities.json`,
`desktop-schema.json`, `windows-schema.json`) are regenerated by `tauri-build` on every
`cargo build`. They were tracked in git, so every local build produced a dirty working tree
even with no real source change, and the fixes in this session had to repeatedly revert
diffs to these files to keep the actual change set readable. `recovar-gui/dist/` is Vite's
build output and was likewise never meant to be committed.

## Files affected

- `.gitignore`
- `recovar-gui/src-tauri/gen/schemas/` (untracked, files kept on disk)

## Verification

`cargo build --release` regenerates `gen/schemas/*.json` as before; `git status` no longer
shows them as modified afterward.
